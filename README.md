I build across Android and the web — from practical utilities and developer tools to web apps, casual games, and health-adjacent experiences. I care about software that stays simple, works offline when it can, and respects the people using it.

- **Web apps & casual games** — a few of them small, a few of them for smaller humans.
- **Cognitive & health-adjacent experiences** — built to be accessible first, not as an afterthought.

*No project names, no links — the work speaks for itself.*

---

## How I work

- Offline-first by default. The network is a feature, not a requirement.
- Small, shippable increments beat big-bang rewrites.
- Tests and accessibility checks live in the loop, not bolted on at the end.
- Secrets stay out of source; configuration belongs in env files.
- AI is an accelerator, not a crutch — usually.
